# DSH 插件选单 dsh-plugin-picker

## 1. 一句话

官方插件中心没有分类，3.5 万个 DeepSeek Harness 插件不知道哪个好用。这个站按用途分类、
上下文占用、更新活跃度、README 完整度四项代码可算的指标打分排序，不按 star 排。

在线演示：https://laomaiai.github.io/dsh-plugin-picker/

## 2. 它解决什么问题

- 官方插件中心没有任何分类，教程原话是很难第一眼就知道插件的作用。
- star 数会误导：dsh-context 4.3K star 是因为人人都需要看上下文，Agentero 19 star 不是它差，
  是它本来就窄。
- 现有市场能按主题搜，但没有评分和上下文成本这类质量信号；教程文章人工精选覆盖面小、会过期。
- 本产品是一个可搜索的网页选单，四项指标全部代码可算，同一输入同一输出。

## 3. 数据来源与覆盖

- 主来源：dsh-market plugins.json（2BingLing/dsh-market，公开数据，每日 06:00 更新）。
  2026-11-16 00:33:26Z 生成的一版共 21,808 条。
- v1 收录 500 条：按 pushedAt 降序、stars 降序、fullName 升序取前 500 条。最近更新优先，
  不是 star 优先。其余条目未逐一拉取 README，未列入 v1。
- 每条数据含插件名、简介（英文原简介与中文机翻简介）、tags、stars、最近推送时间、安装命令，
  以及实测的 README 字符数与标题数、SKILL.md 或 README.md 的字符数。
- 本轮抓取的取到数与失败明细见 scripts/data/fetch-report.json。
- 当前快照（2026-11-16）：README 实测 498/500，SKILL.md 实测 11/500；未取到 README 的 2 条是仓库根目录没有 README 文件（404），其余 489 条没有 SKILL.md 文件，均非拉取失败；本轮拉取失败 0 项。明细见 scripts/data/fetch-report.json。
- 备用来源（未采用）：dsh-plugin-catalog index.json，共 5,643 条，字段较少，只作交叉核对。

## 4. 四项评分规则

- 用途分类（置信度）：关键词规则归类，10 类加其他。命中 1 个关键词 40 分、2 个 60 分、
  3 个 80 分、4 个及以上 100 分；分不出进其他，0 分。
- 上下文占用：指令文件（根目录 SKILL.md 优先，否则 README.md）字符数除以 4 估算 token，
  页面标为估算值。1000 tokens 内 100 分、4000 内 80 分、10000 内 60 分、25000 内 40 分、
  超过 20 分；未取到文件 0 分。
- 更新活跃度：按最近推送距数据日的天数：7 天内 100 分、30 天内 85 分、90 天内 65 分、
  180 天内 40 分、超过 20 分；缺失 0 分。
- README 完整度：存在 30 分；长度 500 字以下加 10 分、2000 字以下加 20 分、5000 字以下加 30 分、
  5000 字以上加 40 分；标题数 1-2 个加 10 分、3-4 个加 20 分、5 个以上加 30 分；满分 100 分。
  未取到 0 分。
- 综合分 = 分类置信度 x 0.15 + 上下文 x 0.30 + 更新 x 0.30 + README x 0.25，保留一位小数。
- 全部规则见 src/lib/scoring.ts，Vitest 覆盖。

## 5. 怎么用

- 搜索框：按插件名、简介、标签搜，支持中文。
- 分类 chips：10 类加其他，带条数。
- 排序：综合评分（默认）、上下文最轻、更新最活跃、README 最完整、最近更新。
  star 数只展示，不参与排序。
- 每行显示四项分值与综合分、安装命令（可复制）、GitHub 仓库链接。

## 6. 本地运行

- `npm install`；`npm run dev`（开发）；`npm run build`（构建）；`npm run test`（Vitest）；
  `npm run fetch-data`（重新抓取数据）。
- 需要 Node 20+ 与 Python 3。

## 7. 数据更新

- 重跑 `python3 scripts/fetch_data.py`（默认取前 500 条），会重新下载来源数据并补取
  README / SKILL.md，成功结果缓存在 scripts/data/cache/，重跑只补缺失的。
  生成 public/data/plugins.json 与 scripts/data/fetch-report.json。
- 数据是快照，不会自动跟进。

## 8. 确定性说明

- 四项指标全部由代码算出，无大模型参与。同一输入同一输出。
- 来源数据的中文简介是 dsh-market 用 DeepSeek 机翻的，本产品只拿它当分类关键词的输入，
  不拿它当评分依据；对方自带的五维评分字段未使用。

## 9. 合规边界

- 本产品不涉及股票、加密、资金托管；不提供安装服务，只做选单。
- 收录只是发现信号，不是安全背书。插件是第三方代码，安装前请自己核对来源与安装命令，
  不要安装来源不明的插件。
- 插件数据来自公开来源，star 数、描述等以来源为准。

## 10. 局限与下一步

- v1 只收录 500 条（来源 21,808 条）；只查根目录 SKILL.md 与 README.md，不查 skills/ 子目录。
- 分类关键词是人工规则，未用来源的 curated 分类做对照验证。
- 数据是快照，需手动重跑脚本更新。
- 下一步：扩大收录量、补 skills/ 子目录的 SKILL.md 探测、加分类规则对照验证。
